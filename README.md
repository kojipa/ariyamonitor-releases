# Ariya Monitor（配布版）

🌐 **English: [README.en.md](README.en.md)**（アプリの画面は英語に切り替えられます。サポートは日本語のみです）

日産アリアのOBD2ポートから、バッテリーの状態などを読み取って表示するAndroidアプリです。
**個人が作った非公式アプリです。日産自動車とは関係ありません。**

> ⚠️ **試験公開中です。** 作者の車（1台）でしか動作を確かめていません。年式やグレードによっては、値が出なかったり正しくなかったりすることがあります。

## ダウンロード

👉 **[最新版のページ（Releases）](../../releases/latest)** を開き、`ariyamonitor-public-x.y.z.apk` をダウンロードしてください。

> 📱 Android 5〜7の端末や、動作が重いと感じる端末向けに **[Lite版（軽量版）](https://github.com/kojipa/ariyamonitor-lite-releases)** もあります。


## できること

- **ホーム**：バッテリーを管理するコンピューター（BMS）が持っているSOC（実SOC）を大きく、メーターの%に近い車のSOC（画面の「METER」）を小さく表示します。「METER」はメーターの表示そのものではないため、少しずれることがあります（例: メーター100%のとき99.28%）。実SOCは満充電で100%を少し超えることがあり、画面では100%までの表示です。電気の流れ（走行中・回生・充電中）を、車の絵の上の光の演出で表示します。演出の強さは「設定」→「表示」の **演出レベル**（STEALTH / CRUISE / SPORT / OVERDRIVE）で選べます。タイヤの空気圧（4輪）・外気温・走行距離も表示します。下の帯には、パック電圧・残エネルギー・車速・バッテリー温度をゲージ付きで出します。数字の書体（Chakra Petch / 標準）と、背景に流すログ（できごとと走行の集計）も「設定」→「表示」で選べます。
- **車両のいま**：バッテリー温度、冷却水温、パック電圧、電流、車速、BMS残エネルギーなどを一覧で表示します。
- **直近15分のグラフ**：選んだ項目の変化を、目盛り付きのグラフで表示します。
- **バッテリー**：駆動用バッテリーのセル96本の電圧と、モジュールの温度（車が返事した数。B6は12個）をマップで表示します。停車中にはばらつきなどから状態の目安を顔のマークで出し、補機バッテリー（12V）の推定電圧や、充電中の容量推定も見られます。接続時に車の型の目安（前期初期型／前期改定後以降）も表示します。測定結果の履歴は端末の中にだけ保存します。セル電圧はマップと棒グラフを切り替えて見られます。
- **充電履歴**：充電を1回ずつ端末の中に記録し、時間・SOCの変化・充電電力量（参考値）・出力・温度を一覧で表示します。タップすると充電カーブ（出力・実SOC・バッテリー温度）が見られます。車の電源を切った充電中も、アプリが動いていれば記録します。
- **自動接続**：アプリを起動すると、OBD2アダプターに自動でつながります。Bluetoothのアダプターでは、つなぎ方を3通り試し、うまくいった方法を覚えます。Wi-Fiのアダプター（v0.3.9〜）、BLEのアダプター（v0.4.0〜）にもつなげます。つながらないときは、理由（Bluetoothがオフ、アダプターのWi-Fiが見つからない、アダプターにつながらない、車から応答がない など）を表示します。
- **英語表示**：「設定」→「表示」の **言語** で、画面を英語に切り替えられます（端末に合わせる／日本語／English）（v0.4.0〜）。
- **走行・充電の記録（CSV）**：「設定」→「記録」で **走行・充電の記録を残す** をオンにすると、接続が切れるたびに、読んだ値をCSVファイルにして、選んだフォルダへ自動で保存します。形式は3種類から選べます。合計100MBを超えると古いものから消します（v0.4.3〜）。
- **画面を消さない**：表示している間、画面が自動で消えないようにできます（オフ／読み取り中だけ／常に。初期値は「読み取り中だけ」）。

一部の項目（電流・SOH・高精度電流・充電電力）と、バッテリー画面の診断・容量推定、ログの走行の集計は **「参考値・非公式の目安」** です。作者の車でも精度を検証しきれていないので、目安として見てください。

## 安全について

- **車には読み取りのコマンドしか送りません。** 書き込み、ECUのリセット、故障コードの消去などは、機能として入っていません。読み取る相手は、バッテリーまわりのECUと、メーター（空気圧・走行距離）・エアコン（外気温）です。空気圧などは走行中に1分に1回だけ読みます。
- 停車中で充電もしておらず、電流がほぼ流れていない状態が10分続くと、読み取りを自動で止めます（補機バッテリーを守るため）。
- 車両のデータを外部に送信しません。アカウント登録もありません。記録のCSVも、端末の中の選んだフォルダに保存するだけです。
- 唯一の通信は、1日1回、このページに新しい版があるかを確認するものです。設定でオフにできます。
- 位置情報は使いません。ただし **Android 11以下の端末でBLEのアダプターを選ぶとき** だけ、端末の仕組み上、位置情報の許可を求めることがあります（アダプターを探すためだけに使い、位置を記録・送信することはありません。Android 12以上、BluetoothクラシックやWi-Fiのアダプターでは求めません）。

## 必要なもの

| もの | 条件 |
|---|---|
| 車 | 日産アリア |
| Android | 8.0以上（スマートフォン、またはCarPlay AIボックスなどのAndroid機器） |
| OBD2アダプター | **Bluetooth（クラシック／SPP）**、**Bluetooth Low Energy（BLE）**、または **Wi-Fi** 接続の **ELM327互換** アダプター |

- Bluetooth（クラシック）のアダプターは、先にAndroidの「設定」→「Bluetooth」でペアリングしておいてください（PINはたいてい `1234` か `0000` です）。BLEのアダプターはペアリング不要で、アプリの中から選びます。
- Wi-Fiのアダプターは、パスワードなしのもの（アダプター自身がWi-Fiを出すタイプ）に対応しています。接続中は端末のWi-Fiがアダプター専用になります（Android 10以上では、ほかの通信はモバイル回線のまま使えます。テザリング（Wi-Fi）でネットにつないでいる車載機などでは、接続中はネットが使えません）。

## インストール方法

1. Androidのブラウザで、最新版のページからAPKをダウンロードします。
2. ダウンロードしたファイルを開きます。
3. 「この提供元のアプリを許可しますか」と出たら、**許可**してから戻り、インストールします。
4. **Google Play プロテクト**の警告が出ることがあります。Google Playを通していないアプリのため、表示されることがあります。
   - 「スキャンせずにインストール」を選ぶか、「詳細」→「このままインストール」で進めてください。

## 使い方

1. 車の電源を入れて、OBD2アダプターを差し込みます。
2. アプリを起動し、注意書きを読んで「同意して開始」を押します。
3. 「設定」→「接続」の **アダプター** の「変更」で、使うアダプター（Bluetooth／BLE／Wi-Fi）を選びます。
   - BLE アダプターは「**BLE アダプターを探す**」で見つかったもの（例: `OBD BLE`）を選びます。BluetoothクラシックとBLEの両対応アダプターは、どちらか一方でしかつながりません。BLEで使うときは、端末のBluetooth設定でクラシック側をペアリングしないでください。
   - Wi-Fi アダプターは、SSID・アドレス・ポートを空欄のままで自動で探します。Android 10以上では、Wi-Fi アダプターの設定で「**アダプターの Wi-Fi を選ぶ（初回のみ）**」を押してアダプターのWi-Fi（例: `WiFi-OBDII`）を一度選んでおくと、次から「デバイスに接続」画面を出さずにつながります（選んでいない場合や、保存したアダプターが見つからない場合は、接続のたびにその画面でアダプターのWi-Fiを選びます）。Android 9以下では、先に端末のWi-Fi設定でアダプターのWi-Fiにつないでおいてください。
4. 「接続開始」を押すと、数秒〜十数秒でホームに値が表示されます（次回からは起動時に自動で接続します）。

ホームの演出が出ない、または CRUISE までに抑えられるときは、端末の「アニメーションを削除」をオフにするか、開発者向けオプションの「アニメーター再生時間スケール」を 1x にしてください（ログ表示も、アニメーションがオフのときは出ません）。

うまくつながらないときは、アダプターを抜き差しする、車の電源を入れ直す、他のOBDアプリ（Car Scannerなど）を終了する、の順に試してください。アダプターは同時に1つのアプリしか接続できません。Wi-Fiのアダプターが見つからないときは、端末のWi-Fi一覧に出ているかを確かめてください（13chなど、端末から見えにくいチャンネルを使うアダプターがあります）。

それでもつながらない・値がおかしいときは、「設定」→「その他」の **デバッグログを記録する** をオンにしてから接続し、**不具合・要望を報告する** から送ってください（デバッグログは「デバッグログ」画面の **[コピー]** で写して貼り付けられます。暗号化されていて作者だけが読めます）。アプリへの要望も同じところから送れます。

## アップデート

新しい版が出ると、アプリに「最新バージョンが公開されました」というお知らせが一度だけ出ます。「設定」→「その他」の **「アプリの更新」** 欄から「GitHubで見る」を押すとこのページが開くので、新しいAPKをダウンロードして上書きインストールしてください。設定は引き継がれます。

> v0.1.x をお使いの場合は、アプリの画面の「新しい版があります」をタップしてください。
