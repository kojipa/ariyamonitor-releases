# Ariya Monitor（配布版）

日産アリアのOBD2ポートから、バッテリーの状態などを読み取って表示するAndroidアプリです。
**個人が作った非公式アプリです。日産自動車とは関係ありません。**

> ⚠️ **試験公開中です。** 作者の車（1台）でしか動作を確かめていません。年式やグレードによっては、値が出なかったり正しくなかったりすることがあります。

## ダウンロード

👉 **[最新版のページ（Releases）](../../releases/latest)** を開き、`ariyamonitor-public-x.y.z.apk` をダウンロードしてください。

## できること

- **ホーム**：SOC（充電率）を大きく表示します。電気の流れ（走行中・回生・充電中）も表示します。
- **車両のいま**：バッテリー温度、冷却水温、パック電圧、電流、車速、BMS残エネルギーなどを一覧で表示します。
- **直近15分のグラフ**：選んだ項目の変化をグラフで表示します。
- **自動接続**：アプリを起動すると、OBD2アダプターに自動でつながります。

一部の項目（電流・SOH・高精度電流・充電電力）は **「参考値」** です。作者の車でも精度を検証しきれていないので、目安として見てください。

## 安全について

- **車には読み取りのコマンドしか送りません。** 書き込み、ECUのリセット、故障コードの消去などは、機能として入っていません。
- 車両のデータを外部に送信しません。アカウント登録もありません。
- 唯一の通信は、1日1回、このページに新しい版があるかを確認するものです。設定でオフにできます。
- 位置情報は使いません。

## 必要なもの

| もの | 条件 |
|---|---|
| 車 | 日産アリア |
| Android | 8.0以上（スマートフォン、またはCarPlay AIボックスなどのAndroid機器） |
| OBD2アダプター | **Bluetooth（クラシック／SPP）** 接続の **ELM327互換** アダプター |

- Bluetooth Low Energy（BLE）専用のアダプターや、Wi-Fi接続のアダプターには対応していません。
- アダプターは、先にAndroidの「設定」→「Bluetooth」でペアリングしておいてください（PINはたいてい `1234` か `0000` です）。

## インストール方法

1. Androidのブラウザで、最新版のページからAPKをダウンロードします。
2. ダウンロードしたファイルを開きます。
3. 「この提供元のアプリを許可しますか」と出たら、**許可**してから戻り、インストールします。
4. **Google Play プロテクト**の警告が出ることがあります。Google Playを通していないアプリのため、表示されることがあります。
   - 「スキャンせずにインストール」を選ぶか、「詳細」→「このままインストール」で進めてください。

## 使い方

1. 車の電源を入れて、OBD2アダプターを差し込みます。
2. アプリを起動し、注意書きを読んで「同意して開始」を押します。
3. 「設定」の **Bluetooth接続先** で、ペアリング済みのOBD2アダプターを選びます。
4. 「接続開始」を押すと、数秒〜十数秒でホームに値が表示されます（次回からは起動時に自動で接続します）。

うまくつながらないときは、アダプターを抜き差しする、車の電源を入れ直す、他のOBDアプリ（Car Scannerなど）を終了する、の順に試してください。Bluetoothは同時に1つのアプリしか接続できません。

## アップデート

新しい版が出ると、アプリの画面に「新しい版があります」と表示されます。タップするとこのページが開くので、新しいAPKをダウンロードして上書きインストールしてください。設定は引き継がれます。
